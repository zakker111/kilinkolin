# Self-hosted fonts

Latin subsets of the three families used by the page, downloaded as WOFF2 from Google Fonts.
They are served from this directory so the map does not wait on a third-party font connection.

- Bebas Neue — SIL Open Font License 1.1
- IBM Plex Mono — SIL Open Font License 1.1
- Inter — SIL Open Font License 1.1

Upstream: https://fonts.google.com/
